### 🌙 **Nightu VPS Maker - Your All-in-One Virtual Server Manager**

Spin up, manage, and control VPS containers like a pro! **nightu-vps-maker** is a sleek Python CLI tool that lets you create, start, stop, and customize Linux VPS instances using Docker or Podman. 

**Key features:**
- ⚡ Create & manage multiple VPS containers in seconds
- 🎮 Intuitive CLI menu with emoji-rich interface  
- 🔧 Adjust CPU, RAM, and disk on the fly
- 🔓 Direct root shell access to your VPS
- 🌐 SSH remote Docker support for headless servers
- 📊 Real-time container stats and VPS monitoring
- 🛡️ Built-in error handling and Docker permission checks

Perfect for developers, sysadmins, and anyone wanting easy local VPS management without the complexity. Works on Linux, macOS (with Docker), and supports remote management over SSH.

**Get started:** Clone, run, and manage your containerized VPS infrastructure in minutes! 🚀
